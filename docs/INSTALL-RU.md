# SelectiveVpn — установка на чистый компьютер

Комплект для Windows 10/11 x64 (Intel/AMD), с правами администратора.
PlanetVPN, .NET и отдельно скачанные VPN-движки устанавливать не нужно.
Установка на чистой виртуальной машине пока не проверена.

## Установка

1. Перенесите ZIP на нужный компьютер и распакуйте его целиком в обычную папку.
   Не запускайте установщик из окна просмотра архива.
2. Если установлен другой VPN, отключите его перед первым подключением SelectiveVpn.
3. Запустите INSTALL.cmd двойным кликом и подтвердите запрос Windows на права администратора.
4. После подтверждения откроется консоль со стадиями установки. Дождитесь открытия SelectiveVpn.
   Если Windows запросит подтверждение для неподписанного приложения, проверьте источник комплекта.
5. В интерфейсе выберите рекомендуемый сервер или конкретную страну/сервер.
   Начните с автоматического выбора протокола. Сторонние Xray JSON, OpenVPN .ovpn
   и WireGuard .conf добавляются на вкладке «Серверы». Там же можно проверить
   доступность сервера, удалить его и открыть справку о форматах.
6. Добавьте нужные приложения, домены или IP/CIDR в правила, сохраните и нажмите «Подключить».

Установщик проверяет контрольные суммы, копирует приложение и оба движка в
C:\Program Files\SelectiveVpn, импортирует включённые настройки провайдера,
загружает каталог серверов и устанавливает службу с автоматическим запуском.
.NET включён в комплект. Файлы вручную переносить не нужно.

Для получения актуального каталога и подключения нужен доступ к API и серверам
провайдера. Установщик ждёт каталог до 45 секунд. Если каталог не загрузился, установка завершается с предупреждением:
повторите обновление каталога в интерфейсе после восстановления доступа.
Пакет не содержит автономной копии всех актуальных серверных профилей.

Секретные настройки на целевом компьютере шифруются заново средствами Windows.
Комплект содержит исходный файл настройки провайдера: храните архив приватно.
Личные правила, пути приложений и зашифрованные данные исходного ПК не переносятся:
пути на другом компьютере могут отличаться. На чистом ПК правила задаются заново.

## Автозапуск и трей

- «При входе открывать интерфейс в трее» — запускает только интерфейс,
  настройка сохраняется сразу для текущего пользователя.
- «Подключать VPN при запуске службы» — подключает VPN при запуске службы, в том числе при загрузке Windows.
- «Подключать VPN при входе в Windows» — подключает VPN при новой пользовательской сессии.
  Настройки VPN сохраняются кнопкой «Сохранить изменения».
- Крестик скрывает окно, двойной клик по значку возвращает его.
- «Выход» завершает интерфейс; служба и VPN продолжают работу.
  Для отключения VPN сначала выберите «Отключить».

## Проверка и диагностика

Сравните SHA256 архива с соседним файлом .zip.sha256:
Get-FileHash .\SelectiveVpn-win-x64-<дата>.zip -Algorithm SHA256

Проверка распакованного комплекта без установки (PowerShell из папки комплекта):
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\Setup.ps1 -CheckOnly

При ошибке автозапуска службы сначала откройте service.log. Там видны попытки очистки VPN-маршрутов и её тайм-ауты. Если запуск окончательно завершился с ошибкой, проверьте журнал Windows «Приложение» и события SelectiveVpn.Service.

Журнал установки: install.log в распакованной папке. Папка может находиться на рабочем столе или на любом локальном диске.
Рабочие журналы: C:\ProgramData\SelectiveVpn\service.log, engine.log, openvpn.log.
Кнопка «Открыть файл журнала» находится на вкладке «Диагностика».
Контрольные суммы обнаруживают повреждения файлов, но не заменяют цифровую подпись.

Проверьте сначала обычное подключение, затем правила IP/доменов и приложений.
Приложения из списка «через VPN» должны терять доступ при отключённом VPN.
Для полного повторного теста предусмотрен scripts\Test-Installed.ps1:
запускайте от администратора после отключения других VPN; он временно меняет
тестовые правила, восстанавливает настройки и останавливает службу в конце.
Результаты появятся в artifacts\acceptance. После теста службу можно запустить через UI.

## Обновление и удаление

Перед обновлением отключите SelectiveVpn и выберите «Выход» в меню трея.
Повторно запустите INSTALL.cmd из нового комплекта. Установка останавливает
существующую службу; сохранённые пользовательские настройки остаются.

Удаление службы и снятие блокировок приложений из PowerShell администратора:
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\Uninstall.ps1 -RemoveApplicationBlocks

Перед удалением выйдите из интерфейса через трей.
Без -RemoveApplicationBlocks защищённые приложения останутся заблокированы.
Удаление оставляет бинарные файлы и зашифрованные настройки для восстановления.

сервисов провайдера. Сведения о сторонних компонентах: THIRD-PARTY-NOTICES.txt.
