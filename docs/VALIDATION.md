# Проверка сборки 0.1.0

Дата: 15 ноября 2026. Среда: Windows x64, .NET SDK 10.0.401, sing-box 1.14.4.

## Выполнено

- Release-сборка службы и WPF без предупреждений и ошибок; автономная публикация win-x64. WPF-окно создано и отрисовано в отдельном smoke-запуске.
- 37 проверок политики и конфигурации: IDN, IPv4/IPv6 CIDR, приоритет приложения, запреты в отключённом состоянии, отказ при неопределённом процессе, проверка реальным движком всех 18 исходных серверных профилей.
- 59 проверок в административном запуске (включая предыдущие): постоянные и загрузочные WFP-фильтры, TCP IPv4/IPv6, отсутствие доставки UDP IPv4/IPv6, допуск только выбранного интерфейса, повторная блокировка, сохранение запрета после аварийного завершения процесса управления, удаление собственных тестовых фильтров.
- Запись и повторное открытие выбранного ID сервера и автоподключения в дисковом хранилище. Запись/чтение профилей через DPAPI; UUID отсутствует в открытом виде в зашифрованном файле.
- Реальный HTTPS-запрос через локальный SOCKS и исходный профиль PlanetVPN node `1001170`: успешный ответ, выход во Франции.
- Реальный TUN с тестовым маршрутом: защищённый EXE выходит во Франции через VLESS; второй EXE по прямому доменному правилу — через основное подключение в Беларуси. В журнале движка подтверждены оба outbound. Приложение блокируется до выдачи допуска и сразу после его отзыва.

Временные WFP-фильтры тестовых приложений удалены после проверки. Никакие серверные UUID, ключи и полный список конфигураций в Git не включены.

## Границы проверки

Полная установка через SCM и работа после перезагрузки Windows требуют отдельной приёмки на целевой системе. Загрузочные фильтры успешно добавлены и удалены через WFP; сама перезагрузка в этой сессии не выполнялась. Не проверялись все 18 серверов живым трафиком, все приложения, взаимодействие со всеми сторонними VPN/антивирусами и долгосрочное восстановление сети после сна.

В обычном режиме тестирования не устанавливается постоянная служба и не заменяется пользовательский маршрут по умолчанию. Для рабочего запуска используйте `scripts/Install.ps1` из README. Результаты тестов не следует трактовать как универсальную гарантию отсутствия любых DNS-метаданных при делегировании запросов системным службам.
